# AI 对话历史 v2 修复(单 conv 文件 + source_path key)

**日期**:2026-07-14
**状态**:已完成
**前置**:v1 commit `ff8c97e`(同上午,首次版本,带双源 bug)

## 1. v1 暴露的两个核心 bug

1. **source_path 漏传** —— AIRightPanel 调 `ai.setCurrentSource(props.filePath)` 传的是**文件相对路径**(如 `"SKILL.md"`),不是磁盘绝对路径。后端 `resolveSkillDirBySourcePath` 校验"必须在 store.root 下 + 含 SKILL.md" → 永远 404 → 用户**看不见对话被保存到历史**。
2. **messagesOf 丢内容** —— store 的 `flushBackend` 把每条 message 裹成 1 元素数组,丢失 `reason/status/needsApply/parseFailed/rawLast` 等字段。一个对话被拆成 N 条碎片。

加上用户原话反馈:**"清空对话改成新建对话"** + **"一个对话的所以上下文使用一个文件保存"**

## 2. 用户决策(已确认)

| 决策 | 选 |
|---|---|
| conv_id 谁生成 | 前端 `conv_<ts>_<seq>`(后端 sanitize `[A-Za-z0-9_-]` 兜底) |
| 单对话 > 2MB 怎么办 | 直接返错 400 `conv_too_large` |
| archive 失败 | 先清本地后写后端,失败 toast(用户已勾) |

## 3. 实施(6 Phase)

### Phase B1 — `skillboxdata` 新增单 conv 文件 API(2026-07-14 v2 增)

新增:
- `ErrInvalidConvID` / `ErrConvTooLarge` / `MaxConvSize = 2MB` / `HistoryDir = "history"`
- `ConvMeta{id,title,preview,provider,model,ts,size}` — metadata 视图
- `sanitizeConvID(id) (string, error)` — 强白名单 `[A-Za-z0-9_-]`,拒空 / `..` / 任何控制字符
- `ConvFile(skillDir, convID) (string, error)` — 拼 `<skillDir>/.skill-box/history/<safe-id>.json`,非法 conv_id 直接返 error 不写盘
- `ListConvs(skillDir) ([]ConvMeta, error)` — directory-only,**不读 messages**;目录不存在返空;坏 json 跳过不 panic;按 ts desc
- `ReadConv(skillDir, convID) (*HistoryItem, error)` — 完整(含 messages);不存在返 `(nil, nil)`
- `WriteConv(skillDir, item) error` — upsert + atomic rename + preview 兜底;>2MB 返 `ErrConvTooLarge`
- `DeleteConv(skillDir, convID) error` — 幂等,不存在不报错

`WriteConv` 路径内部 `os.MkdirAll(history/)` 确保子目录存在(Ensure 只创 `.skill-box/`)。

测试加 7 个用例:round-trip / upsert / 2MB 截断 / ListConvs 0/1/N+坏文件+ts desc / DeleteConv 幂等 / sanitize。

### Phase B2 — `sai.Service` 扩 4 方法

复用 v1 的 `resolveSkillDirBySourcePath`(已实现)。新增:
- `ListConvs(sourcePath)` → metadata
- `GetConv(sourcePath, convID)` → 完整,不存在 (nil,nil)
- `SaveConv(sourcePath, item)` → upsert
- `DeleteConv(sourcePath, convID)` → 幂等

保留 v1 函数(`SaveHistory / ListHistory`)作 legacy,前端走 v2。

### Phase B3 — controller 改 2 + 新增 2

- 改 `save_history.a.go`:body `{source_path, item}` 单条 upsert;ErrConvTooLarge → 400 `conv_too_large`
- 改 `list_history.a.go`:返 `{items: []ConvMeta}` metadata-only
- 新增 `get_history.a.go`:GET `?source_path=&conv_id=` → 完整,不存 404
- 新增 `delete_history.a.go`:POST(ginp 未实现 HttpDelete,统一走 POST)

### Phase E — 4 层 prop drilling(关键修复)

`SkillsView.currentSkillSourcePath = computed(c._full?.canonical?.source_path || c._full?.source_path)` → 透传到 `SkillFileInlinePanel(source-path)` → `CodeViewer(source-path)` → `AIRightPanel(source-path)` 两处。

AIRightPanel:
- `defineProps.sourcePath:{type:String,default:''}`
- `watch(() => props.sourcePath, ai.setCurrentSource, { immediate: true })` —— 用 immediate,避免 onMounted 时序
- 旧的 `watch(filePath)` + `setCurrentSource(filePath)` 全删
- 同 skill 多文件共享同一会话(sessions key 是 source_path)

### Phase D — `useAiStore` v2 重写

删除 v1 不再需要的东西:
- `clearCurrent` / `_scheduleBackendSave` / `_saveTimer` / `flushBackend` / `messagesOf` / `defaultTitle` / `defaultPreview` —— 整段删

新增 v2 action:
- `archiveCurrent()`:**先本地清空 sessions[k],再 await api.saveHistory**;失败抛错让组件 toast。空会话 / 无 source 路径时 no-op。
- `pickHistoryItem(meta)`:异步 — GET 单条 → 装填完整 messages 到 sessions(用 `JSON.parse(JSON.stringify(item.messages))` 深拷贝);失败抛错。
- `deleteHistoryItem(convId)`:`api.deleteHistory` → 移除 historyItems。
- `hasCurrentContent` getter:有 messages 时为 true。

保留 v1 action(`pushUser / pushAssistantPlaceholder / patchAssistant / setMessageApplied / setMessageRejected / setCurrentSource / openHistory / closeHistory / loadFromBackend`)—— 全部保留全字段,**不再裁剪**。

**持久化策略**:活跃会话 → localStorage(草稿);归档 → 后端单文件(权威)。

### Phase A + F — UI + i18n

- AIRightPanel 头部第二个图标:`mdi:delete-outline` → `mdi:plus-circle-outline`,tooltip "新建对话",点击调 `newConversation()` → `ai.archiveCurrent()`;空会话 / savingConv 期间禁用
- AIHistoryDialog:每项右上角加 ✕ 删除按钮(`stopPropagation` 不触发 pick);loading 项标 `ai-hist-item-saving`,overall `disabled`;失败 toast
- i18n zh-CN / en-US 补:`newConv / archiveFailed / deleteConv / deleteFailed / loadFailed`(沿用 v1 history + historyDialog.*)
