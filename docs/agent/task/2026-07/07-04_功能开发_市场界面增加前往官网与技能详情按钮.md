## 4. 关键设计决策

### 4.1 跨平台"打开外链"统一走 `platform.platform.openExternal`

- 已有封装:`frontend/src/platform/index.js` 的 `createWebPlatform`/`createDesktopPlatform`
- Web 端: `window.open(url, '_blank', 'noopener')`
- Desktop 端: POST `/api/desktop/open-external` → 桌面 hook 走 `platform.BrowserOpenURL`
- MarketView 直接复用,无需自建 endpoint 或前端 bridge

### 4.2 后端 source 主页 URL 派生

- 需求点是"原市场的官网" — skillhub 的 API host 是 `https://api.skillhub.cn`,官网却是 `https://skillhub.cn`;skills.sh 单 host。
- 选 `MarketAdapter.HomepageURL(sourceConfigJSON string) string` 接口,内置默认表:
  - skillhub → `https://skillhub.cn`
  - skillssh → `https://skills.sh`
  - custom → 从 `config_json.base_url` 派生 origin
- 不在 `entity.MarketSource` 写盘(homepage 是 UI 派生属性),用 `SourceWithHomepage` 包装类型 + `MarshalJSON` 打平序列化
- `ListSources.Items` 类型从 `[]*entity.MarketSource` 改成 `[]*SourceWithHomepage`,JSON 形状完全向后兼容(老字段全有 + 多了 homepage)

### 4.3 skill 详情 URL 字段已存在

- `entity.MarketSkill.DetailURL` 字段已持久化到 `market_skills.detail_url`
- skillhub adapter 优先取 `apiSkill.Homepage`,空时回退 `{baseURL}/skills/{slug}`
- skills.sh adapter 拼接 `{baseURL}/{source}/{skillId}`
- 前端 `loadSkills` 拿到的 item 直接带 `detail_url` 字段,无需后端改动

### 4.4 按钮位置与样式

- 工具栏"前往官网":放在"源设置"按钮左侧,`v-if="activeSource?.homepage"` 控制显隐;title 给完整 URL 提示
- 卡片底部"前往技能详情":放在眼睛按钮右侧,`v-if="it.detail_url"` 控制(空 URL 降级隐藏而非 disabled)
- 卡片底部新增 `.market-card-detail-icons` 容器,把两颗 icon 并排(gap: 4px),不影响右侧拉取按钮
- hover 主题色沿用市场主色 `--mkt-primary`,与拉取主操作视觉区分
