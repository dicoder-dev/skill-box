**日期:** 2026-07-18
**状态:** 已完成

## 1. 需求

用户对 SkillFileInlinePanel 下方三个面板提了两点反馈:

1. **面板高度限制**:Skill 作用域 / 版本历史 / Get 同步三个面板展开后内容
   可能很长(尤其是作用域工具很多时、历史 commit 列表很长时),把详情区底
   部撑得很高,文件树区域被压缩。需统一加最大高度 + 内部滚动。
2. **历史时间精确到分钟**:版本历史面板当前只显示日期 (YYYY-MM-DD),用户反
   馈同一天多次 commit 看不出顺序,改成具体到分钟 (YYYY-MM-DD HH:mm)。

## 4. 问题与方案

### 4.1 Scope 面板不用改?

- SkillScopePanel 的 `.ssp-scope.is-expanded` 已经有 `height: 300px; flex: 0 0 300px;` 锁死,
  内部 `.ssp-scope-list` 也已经 `overflow-y: auto`。展开态下工具列表/全局 Agent tag
  高度被锁在 300px,内部滚动。**Scope 面板已经满足"最大高度 + 内部滚动"要求**,本次无需改动。
- 跟用户对完需求:确认 Scope 面板本来就是锁死高度的,反馈里"三处都限"其实是担心它,
  实际它没问题。只补 History + GitSync 两处即可。

### 4.2 CSS 变量而非硬编码

- VersionHistoryPanel 的 max-height 走 `var(--vhp-list-max-h, 320px)` 默认 320px,
  GitSyncPanel 走 `var(--gsp-content-max-h, 320px)` 默认 320px。
- 这样后续如果父级布局 (SkillFileInlinePanel) 想覆盖,直接给 `.sfip-left` 设变量
  即可,不用改组件源码。
- 默认值跟作用域面板的 300px 接近(给到 320px 是为了多容纳一两个 commit / KV 行),
  三面板视觉重量统一。

### 4.3 全局隐藏滚动条惯例

- 项目 memory 里 [[fe-hide-scrollbar-everywhere]] 明确:桌面软件风格不显示滚动条,
  CSS 双层即可 `::-webkit-scrollbar { display:none } + scrollbar-width: none`。
- vhp-list / gsp-content 都按此惯例隐藏,跟作用域面板的 `.ssp-scope-list`
  已有的 scrollbar 隐藏保持一致。
