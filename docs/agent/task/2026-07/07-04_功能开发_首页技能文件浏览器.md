## 4. 问题与方案

**Q: 为什么不复用 Modal.vue？**
A: Modal 是居中弹窗（max-height:84vh + 缩放动画 + 居中遮罩），与"右侧贴边抽屉"形态冲突。新建独立 SkillFileDrawer，Teleport to=body + position:fixed;right:0 + 滑入动画。

**Q: 为什么不复用 TreeNode.vue？**
A: 现有 TreeNode 2026-07-03 改成单级拍平（首页分组只支持单级），且节点数据带拖拽 / 右键菜单 / 工具 chip 这些文件树不需要的能力。新建 FileTreeNode / FileTreeView，节点数据更简单：{type:'dir'|'file', name, path, children?, files?, size?}。

**Q: SKILL.md 默认选中？**
A: 是。watch modelValue 打开时默认选 SKILL.md（如果存在），否则选第一个文件。
