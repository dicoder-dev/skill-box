## 4. 问题与方案

### Q1:`s.audit` 第三个参数 `targetID uint` 改名后语义丢失

- 原签名:`audit(targetID uint, name string, payload map[string]any)` — targetID 形同虚设(2026-06-24 改造时已弃用,实际查询靠 action + name 过滤)
- 新签名:`Event(action, name string, fields map[string]any)` — 去掉 targetID,语义更直接
- 副作用:payload 里的 `"name"` 字段不再需要(已作为独立参数传入),删除对应行

### Q2:`s.audit` 里从 payload 里读 `action` 的旧 hack

- sskillapp 旧代码:`action := "skill_apply"; if mp, ok := payload.(map[string]any); ok { if a, ok2 := mp["action"].(string); ok2 { action = a } }`,然后用读出来的 action 写 audit_log
- 现在:每个 audit 调用点都是 `s.Event(<action>, name, map)`,action 直接作为第一参传,不再需要从 payload 反推
- 改完后少了一层 indirection,代码更直接

### Q3:`pkg/task` 测试卡 10 分钟超时

- `go test ./...` 全跑时 `ginp-api/pkg/task` 的 `TestRun` 是常驻循环测试,等不到它自然退出 → 跟本次改动无关,跳过
- 实际自测只跑改动相关包

### Q4:vet 在 `pkg/logger/logger.go` 报三个错

- `pkg/logger/logger.go:102 missing ... in args forwarded to printf-like function` 等三条
- 全部是项目原有的 vet 警告,不是我引入的;`go test` 时用 `-vet=off` 跳过,build 不受影响
- 不在本任务修复范围(修复属于独立任务),记录在此提示后人
