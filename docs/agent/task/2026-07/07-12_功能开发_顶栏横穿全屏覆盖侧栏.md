# 顶栏横穿全屏覆盖侧栏

**日期:** 2026-07-12
**状态:** 已完成

## 1. 需求

用户提出:优化工具顶部的工具栏,顶部的宽度横穿整个屏幕。顶部的宽度是占满的,包括左侧导航栏也要被顶部覆盖。

即:顶栏不再缩在 main-content 内部,提升为 app-container 的独立行,横穿整个屏幕宽度(包含 sidebar 所在 0~64px 区域)。

## 2. 改动方案

### 2.1 模板结构重构
- `.app-container` 由 `flex` 改为 `flex-col`(垂直)
- 第一行:`<header class="topbar">` 提到 app-container 顶部,横穿全屏
- 第二行:`.body-row` 包住 sidebar + main-content
- 桌面端 sidebar 改为 `fixed` 定位(脱离 flex 文档流),top 从 `var(--topbar-h)` 开始
- main-content 桌面端加 `padding-left: 64px` 让位 fixed 侧栏

### 2.2 CSS 变量
- `.topbar` 上声明 `--topbar-h: 48px`
- `.topbar.mac-desktop` 覆写为 `--topbar-h: 98px`(48 + 50 红绿灯让位)
- sidebar 的 `:style` 用 `var(--topbar-h, 48px)` 引用,自动跟随 mac 模式变化

### 2.3 z-index 协调
- `.topbar` z-index = 45(浮在 sidebar 之上,横穿屏幕)
- `.sidebar` z-index = 35(浮在 main-content 之上,被 topbar 压住左 64px)
- 移动端遮罩 z-30(不挡 sidebar)

### 2.4 删除冗余
- 删掉 `v-if="isMacOS"` 的 `sidebar-top-spacer`(50px 红绿灯让位区)
  - 顶栏现在统一在 z=45 横穿,sidebar 从 topbar 下方开始,红绿灯只落在顶栏区域,不会延伸到侧栏,spacer 不再需要

### 2.5 移动端适配
- mobile 模式 sidebar 抽屉 top 也用 `var(--topbar-h)`,从顶栏下方开始
- mobile 模式 main-content 用 `w-full` 不加 padding-left(抽屉盖住 main-content 但不挡顶栏)
- @media (max-width: 768px) 把 `.main-content-desktop` 的 padding-left 覆盖为 0

## 3. 关键文件

- `frontend/src/App.vue`(模板重构 + CSS 改造)
- `api-server/cmd/web/frontend/dist/`(同步构建产物给 web 端)

## 4. 验证

- `npx vite build` 通过(12.37s / 11.72s)
- 同步 dist 到 web 部署目录
- macOS 桌面端:`--topbar-h: 98px`,sidebar 从 98px 起,主内容 logo 与红绿灯垂直错开
- 桌面端 web/win/linux:`--topbar-h: 48px`,sidebar 从 48px 起
- 移动端:sidebar 抽屉从顶栏下方开始,顶栏 logo 不被挡
