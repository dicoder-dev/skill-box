# AI 历史 v2 用户反馈修复(2026-07-14 晚)

**日期**:2026-07-14 晚(继 v2 `af3ab2c/f41562d` 之后)
**状态**:已完成
**触发**:用户反馈 4 个问题 → 同一次会话内修复

## 1. 用户反馈 4 点

1. **"保存失败呢"** —— POST `/api/skillbox/ai/history/save` 返 404(96µs 内快速返回)
2. **"应该是发消息后自动保存"** —— 当前是手动 +新建对话 → 该改成"发消息后默默归档,带自动 title 推导"
3. **历史对话 / 新建对话 图标显示不出来**
4. **"AI 聊天面板就不需要大纲返回大纲这个图标了"** —— 删掉 switchToOutline 按钮

## 2. 根因分析

### 2.1 404
后端 `resolveSkillDirBySourcePath` 触发 404,但 controller 不打日志 → 看不到真实 sourcePath 字符串。前端 POST 失败后 archiveCurrent catch 又静默。用户层面:"保存失败呢",但没有任何细节。

**本轮修复**:controller / service 加 `logger.Warn` 打印真实 source_path、real、root、SKILL.md 错,下次出问题能立刻看到。
**注意**:本轮**没有**改后端校验逻辑 —— 真正的 source_path 漂移根因没定位(可能是前端拿到的 path 与 store.root 的 EvalSymlinks 链不一致),需要下次复现时看日志。

### 2.2 自动保存
用户原意:AI 流式输出完成(消息 done)→ 自动归档该段会话到历史。**导出的 title 是首条 user 消息前 30 字**(store.archiveCurrent 已带此逻辑)。

**实现点**:
- store.patchAssistant 检测 `patch.status === 'done' && prevStatus !== 'done'` → 触发 `_scheduleAutoArchive()`
- 1.5s debounce 合并同会话的多次 done 帧(retry 期间也会重置 timer)
- _runAutoArchive:写 history.json(不主动清空本地,**留上下文**)
- 利用 sessions[k].convId,同一会话多次自动归档 upsert 同一文件,直到用户点"+ 新建对话"

### 2.3 图标 fallback 不存在
iconparkMap 没 `history` / `plus-circle-outline` 映射 → fallback 到 Help(问号)。

**确认**:iconpark 包**实际导出 PascalCase**:`History`, `AddOne`, `HistoryQuery`, `Comment`, `ApplicationMenu` 等。只是 map 没添加。

**本轮修复**:在 MDI_TO_ICONPARK 表加 `history → History` / `plus-circle-outline → AddOne` 等映射,触类旁通补 `comment-outline / application-menu / file-text-outline / list-view`。

### 2.4 删切换大纲按钮
用户明确不要。删除后,AI 面板的"切到大纲"语义去掉。

## 4. 关键设计点

- 自动归档**不主动清空本地会话**(设计相反于 `archiveCurrent`)—— 让用户继续在同一会话发消息时,done 后还能自动归档到同一 convId,直到用户点"+ 新建对话" 才清空。
- 自动归档失败 → store._archiveError(非 null)→ AIRightPanel watch 后 toast
- watch 的 immediate / immediate-on-sourcePath 仍然是 setCurrentSource,sourcePath prop 链路 v2 已修好
- 后端 controller 失败时本来已有 logger.Error,这次**额外加 logger.Warn 在校验细节处**,便于调试
