# 技能详情作用域面板固定高度

**日期:** 2026-07-08
**状态:** 已完成

## 1. 需求
首页 SkillsView 右栏的 SkillFileInlinePanel 左侧是文件树 + 底部的作用域区(SkillScopePanel)。
当前作用域区用 `max-height: 45% + overflow: auto + flex-shrink: 0`,问题:
- 折叠态(只显示 header)时 panel 占空间小
- 展开态下,如果内容总高度 < 45% 父高,panel 会被内容撑到内容高度(因为 max-height 是上限不是下限)
- 内部 list 没有 overflow,展开 tool 的 targets 列表会直接撑开 panel,挤压 .sfip-tree-wrap(文件树)空间

用户原话:"首页技能详情中 skill 作用域固定高度,点击工具展开时此面板高度不能变"。

## 4. 问题与方案
> 实施过程中遇到的非平凡问题

**问题 1:max-height 是上限,不是下限**
原代码 `max-height: 45%; overflow: auto; flex-shrink: 0` —— max-height 只是"不许超过 45%",内容少时不会强制占满 45%。所以"折叠态"和"展开 1 个 tool 后的展开态"两个 panel 高度不一样,正是用户感受到的"高度变化"。

**方案**:把 panel 自身高度锁死成固定值(280px),内部 list 走 `overflow-y: auto`。
- 折叠态:只显示 header,高度由内容自然撑开(不锁)
- 展开态:height: 280px + flex: 0 0 280px,内部 .ssp-scope-list `flex: 1 1 auto` + `overflow-y: auto`

CSS class 切换用 `<section :class="['ssp-scope', { 'is-expanded': !sectionCollapsed }]">`,配合 v-if/v-else 走正常生命周期。
