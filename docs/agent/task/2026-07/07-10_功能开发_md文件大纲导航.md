# md 文件详情区增加大纲导航

**日期:** 2026-07-10
**状态:** 完成,commit 6ad9ad0(v1 基础) + 25871ee(v2 收起+美化) + acf4e04(v3 icon fix) 已 push

## 1. 需求

用户原话:
> 技能详情对于 md 文件 我希望在右侧区域显示一个大纲导航,按照标题为导航
> 点击后可以快速跳转到指定标题所在区域

后续追加:
> 大纲可以收起,在编辑图标右侧新增对应的图标进行隐藏和展示大纲吧,
> 并且记住状态,这个状态是全局的,隐藏大纲的话打开其他文件默认也是隐藏的
> 还有美化一下大纲的滚动条以及大纲面板的背景色 背景色改白色吧

核心诉求:
1. md 文件(view 模式)在右侧显示大纲导航
2. 按标题(h1-h6)分组
3. 点击大纲项快速跳转到对应标题所在区域
4. 大纲可收起,顶栏编辑按钮右侧新增 toggle 按钮
5. 收起状态全局记住(用 localStorage,跨文件 + 跨刷新保留)
6. 美化滚动条(细 + 浅灰 + hover 变深)
7. 大纲背景改白色

## 2. 实现方案

### 2.1 markdown_view.js 增强

- 重写 `heading_open` rule:渲染时给每个 h1-h6 加 `id="md-h-{slug}"`
- slug 化:小写 + 去标点 + 空格转 `-`,兼容中文
- 同名标题用 env._headingIdCounts 自动追加 `-1` / `-2`
- 新增 `extractHeadings(src)`:走 md.parse 拿 tokens,组装 {level, text, id} 列表
- id 生成规则跟 render 严格一致(共用 slugifyHeading + 计数)

### 2.2 useMdOutlineVisible composable (v2 新增)

- 模块级 Ref<boolean> 单例,整个 app 共享
- localStorage `skillbox.mdOutlineVisible` 持久化(`'0'` / `'1'`)
- watch 触发写入,try/catch 兜底隐私模式 / 磁盘满
- 默认 `true`(显示),用户首次使用不会看到空 panel
- 暴露: outlineVisible / toggleOutline / showOutline / hideOutline

### 2.3 CodeViewer.vue 改造

**v1:**
- 改 `.cv-md-wrap` 为两列:cv-md-content(占满) + cv-md-outline(220px 固定宽)
- 大纲只在 view 模式 + 有标题时显示
- 编辑模式不显示大纲(由 Tiptap 自己管 outline,避免冲突)
- 缩进按"最小 level 提一档"算
- 点击大纲项 `scrollIntoView({ behavior: 'smooth', block: 'start' })`
- 目标标题加 `cv-md-heading-active` 类(1200ms 蓝色背景渐隐)做视觉反馈

**v2:**
- 大纲 aside 改为受 `outlineVisible` 控制:`!editable && mdHeadings.length && outlineVisible`
- 大纲 panel 背景改纯白 `#ffffff`
- 自定义 webkit 滚动条(6px 细 + 浅灰 thumb + 白色 border,hover 变深)
- header 右上角加收起按钮(22×22 小尺寸,跟 count 徽章风格统一)

### 2.4 SkillFileInlinePanel.vue 顶栏按钮 (v2 新增)

- 编辑按钮右侧加 toggle 按钮,`sfip-mode-btn` 风格统一
- 用 bookmark-plus/minus 图标暗示当前状态(展开→收起,收起→展开)
- data-tip 同步切换文案("隐藏大纲" / "显示大纲")
- 调 `useMdOutlineVisible().toggleOutline()`,跟 CodeViewer 内 toggle 共享

## 3. 验证
