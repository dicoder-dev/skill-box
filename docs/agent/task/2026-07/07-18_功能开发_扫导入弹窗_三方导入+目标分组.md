**日期:** 2026-07-18
**状态:** 进行中

## 1. 需求

用户要优化首页"导入技能"弹窗(`OnboardingImportDialog`),具体:

1. **新增「从三方导入」Tab**,放在首位,只放一个 URL 输入框,后端统一调度(skillhub.cn / skills.sh / GitHub)。
2. **「扫描工具」的名称更改为「工具」**,改为「从工具导入」(保持 tab 文字简洁)。
3. **从三方导入**功能:用户直接粘详情页 URL,系统自动识别市场并导入。
4. **后端新增统一调度管理接口**(决策:不新开 endpoint,扩展现有 `install-from-input` 加 `group_path`)。
5. **市场来源列举与引导**:把 Skill Hub / skill.sh / GitHub 三个市场源都列出来,带跳转官网,加操作提示。
6. **所有 Tab 共享「目标分组」选择器**(弹窗顶部 tab 上方一行),默认根分组。
   - 本次只让 market tab 实际生效,其他 3 tab 走默认分组(UI 上选择器对所有 tab 可见)。
