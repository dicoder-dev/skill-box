## 4. 问题与方案

### 问题 1:v2 给的 32px 仍不够

> 现象:macOS 桌面端第一个导航图标和 macOS 标题栏的红绿灯(关 / 最小 / 最大三按钮)垂直重叠。
> 定位:wails3 默认 trafficLightInset 标题栏在 macOS 上实际占用约 38-44px,v2 估的 32px 偏小。
> 方案:.sidebar-top-spacer height 32px → 44px;同时把注释里"原 56px 太多空白"那段过时的话术改成现在的依据。
> 教训:**桌面应用标题栏实际高度不要凭直觉估**,要么查 wails3 文档 / SDK 源码拿真实数值,要么先用浏览器 DevTools 量出红绿灯到第一个图标内容的实际距离再反推。

### 问题 2:v1 把 brand 误改成 Q Boss

> 现象:用户在桌面端看到 logo 文字显示 "Q Boss",不是项目原本的 "Skill-Box"。
> 定位:v1 commit 时直接把 brand 从 'Skill Box' 改成 'Q Boss',这是用户提到的设计意向(把 Q Boss 作为 Logo 区),但当时没确认就用上,造成事实错误。
> 方案:回滚 brand 字段到 'Skill-Box';**同时提醒**:Q Boss 作为产品候选名应另起一轮需求确认,不在本次改 logo 命名时直接换。
> 教训:**改文案字段前必须确认是字符级调整还是产品级调整**,v1 时直接把 brand 换成 Q Boss 是没确认就动了。
