# 技能页主体区去除外边框

**日期:** 2026-10-30
**状态:** 已完成

## 1. 需求
用户原话:「首页布局中,技能菜单在的主体区域有一个大的边框框着 帮我去掉这个边框」。

即:技能(Skills)页面的主体区域外层有一个明显的矩形边框 + 圆角,要求去掉,
让技能页与其他视图(市场 / Agent / 项目)保持一致的平铺无外框风格。

## 3. 执行进度
- 16:20 定位到 `frontend/src/views/SkillsView.vue` 的 `.skills-layout`,
  其上有 `border: 1px solid var(--border)` + `border-radius: var(--radius)`,
  而 `.market` / `.agents-view` / `.projects-view` 均无外框,确认这就是用户说的"大边框"。
- 16:25 删除 `.skills-layout` 的 border / border-radius,保留 `overflow: hidden`
  (用于裁剪左右两栏子面板,不是视觉边框)。
- 16:30 启动 `npm run dev`,用 ego-browser 打开 127.0.0.1:5173,
  通过 `getComputedStyle` 确认 `border-top: 0px none`、`border-radius: 0px`,截图确认视觉无外框。

## 4. 问题与方案
- **问题**:技能页 `.skills-layout` 是唯一带外框的主视图容器,跟其他视图风格不一致。
- **方案**:只删 `.skills-layout` 的 border / border-radius,不碰内部
  `.skills-pane` 的 `border-right`(那是左右两栏之间的分隔线,属于必要信息)、
  `.left-topbar` / `.left-search` 的 `border-bottom`(列表内部区块分隔),
  以及移动端 media query 里的 `border-bottom`。
- **教训**:「去掉边框」要区分"容器外框"和"内部区块分隔线",后者承担视觉分组作用,
  一并去掉会让左栏变成一块糊在一起的白色区域。
